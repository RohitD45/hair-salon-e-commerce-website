# MP09 Family Saloon - Full Stack Web Application

A complete Hair Salon Management System built with Java Spring Boot and MySQL.

## 🚀 Tech Stack
- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA
- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
- **Database:** MySQL
- **Template Engine:** Thymeleaf

## ✨ Features
- Beautiful responsive salon website
- Auto sliding image gallery
- Location-wise team management (3 branches)
- Real-time appointment booking system
- Secure Admin Panel with login
- Appointment status management (Confirm/Cancel)
- Admin password change & new admin add
- Google Maps integration for all 3 locations

## 📍 Locations
- Bhawar Kua, Indore
- Ranjeet Hanuman Road, Indore
- Kesar Bagh Road, Indore

## 🛠️ Setup
1. Clone the repository
2. Create MySQL database: `CREATE DATABASE hairsalon_db;`
3. Update `application.properties` with your MySQL credentials
4. Run `HairSalonApplication.java`
5. Open `http://localhost:8080`

## 👤 Admin Panel
- URL: `http://localhost:8080/admin`
- Default credentials set via DataInitializer
